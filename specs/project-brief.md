# Project Brief: Midnight Shayo

## Vision
A single-page cultural site. index.html describes Midnight Shayo as a movement for Nigerian Gen-Zs. Event galleries are components on that page.

## Target User
Someone discovering the events, and the editor adding a gallery.

## Success Criteria
- [ ] npm run dev serves the Midnight Shayo page on port 8080.
- [ ] Event galleries added in the June 2025 commit render on the home page.

## Out of Scope
- A second product surface. The router has one page.
- A test suite.
